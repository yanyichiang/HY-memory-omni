# Live acceptance fixtures

B, C and D are generated meeting notices, not real user media. `knowledge.json` records the scripted ground truth and is used only by the verifier, never sent to a provider. A is generated from its literal text in the runner. `meeting.wav` is the soundtrack of the same scripted M42 video, exported as mono 16 kHz PCM; it introduces no new speech. Existing tone and synthetic M42 fixtures are under `memory/test/fixtures`.

The scenarios check conflict without automatic revision, different-event separation, explicitly evidenced revision, source withdrawal and original-media reinspection. They are deliberately small regression cases, not a general retrieval benchmark.

`proposal.m4a`, `proposal.opus`, `proposal.flac` and `proposal.aac` derive from the first 7.043 seconds of that same synthetic `meeting.wav`. The utterance proposes Friday for meeting M42; it does not contain a final decision. FFmpeg generated AAC-LC M4A (64 kbit/s), Ogg Opus (48 kbit/s) and native FLAC; ADTS is a packet-copy export of the M4A. Metadata is stripped. ADTS retains transport priming/padding and Opus uses its native 48 kHz decoding clock, so encoded sample counts need not match the input WAV. The `formats` live profile ingests M4A and queries it with the other three native formats, then checks original readback, reinspection and revocation. Model answers are not included in these fixtures.
