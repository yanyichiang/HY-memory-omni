# Bounded GIF frame adapter

`gif-stream.mjs` yields one composited logical-screen RGBA frame at a time. It preserves source frame indices, raw GCE delays (including zero), disposal, background, pixel aspect and raw loop metadata. One source cycle is decoded; infinite loops are not expanded. `gif-adapter.mjs` retains the equivalent array API for isolated decoder tests.

`vendor/index.js`, `deinterlace.js` and the patched `lzw.js` derive from [gifuct-js 2.1.2](https://registry.npmjs.org/gifuct-js/-/gifuct-js-2.1.2.tgz), MIT; retain `LICENSE.gifuct-js`. The original LZW source and `gifuct.patch` show modifications. The package parser is replaced by the bounded envelope parser, and its artificial zero-delay substitution is removed. Strict LZW validates dictionary references, exact pixel count and mandatory EOI instead of filling truncated pixels with zero. The envelope independently validates complete subblocks and trailer. As specified in [GIF89a Appendix F](https://www.w3.org/Graphics/GIF/spec-gif89a.txt), EOI terminates LZW processing; unused packing bytes after EOI are not decoded as further image pixels. In particular, FFmpeg's valid final zero packing byte must not be mistaken for incomplete or extra pixels.

Limits: input 8 MiB, canvas 1,048,576 pixels, side 4096, 128 frames, cumulative decoded work 32 MiB. Disposal 0/1/2/3, local palettes, transparency and interlace are implemented. Missing global background is represented transparently and named as such. Plain-text blocks, user-input waits, unknown extensions/applications and reserved disposal values are rejected. This is a supported subset of GIF, not browser-identical rendering.

The production wrapper converts animated frames to a bounded H264 derivative, retaining source times and the actual mux mapping. Zero-duration frames affect subsequent composition but have no displayed interval. All-zero animations are rejected rather than assigned invented timing. The binary GIF remains the evidence authority.
